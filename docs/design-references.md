# Referensi pengalaman pengguna Food Ilee

Riset ringkas, 24 Oktober 2026. Referensi ini menjadi arah desain, bukan contoh untuk disalin persis.

| Referensi | Temuan yang dipakai | Penerapan di Food Ilee |
| --- | --- | --- |
| [Too Good To Go](https://www.toogoodtogo.com/en-us/find) | Pesan manfaat langsung dan ajakan untuk menemukan makanan di sekitar pengguna. | Hero dan marketplace menjelaskan manfaat sebelum menampilkan produk. |
| [Olio](https://olioapp.com/en/) | Manfaat dijelaskan lewat blok visual dan langkah yang mudah dipindai. | Panel cerita berfoto, contoh pemanfaatan, serta ajakan untuk berbagi bahan. |
| [Baymard Institute](https://baymard.com/research/ecommerce-product-lists) | Daftar produk perlu mendukung pencarian, filter, pengurutan, dan perbandingan cepat. | Pencarian, kategori, urutan harga, serta kartu produk dipertahankan dan dirapikan. |
| [Nielsen Norman Group](https://www.nngroup.com/articles/empty-state-interface-design/) | Keadaan kosong perlu menjelaskan status dan memberi jalan langsung ke tugas berikutnya. | Hasil pencarian kosong memiliki tombol hapus filter; dashboard baru memberi tiga langkah awal. |
| [web.dev](https://web.dev/articles/prefers-reduced-motion) | Gerakan dekoratif perlu menghormati preferensi pengurangan gerak. | Transisi visual baru dinonaktifkan saat `prefers-reduced-motion: reduce`. |

Foto contoh marketplace bersifat ilustrasi, diberi label **CONTOH**, dan tidak dapat dipesan. Foto sayuran dan kulit pisang berasal dari [Unsplash](https://unsplash.com/license); salinannya disimpan di `frontend/assets` agar ikut dibangun menjadi aset dengan nama berbasis hash dan dapat di-cache oleh browser.
