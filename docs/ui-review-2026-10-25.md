# Food Ilee interface review — 25 October 2026

## Changes

- Added a shared finishing stylesheet for quieter backgrounds, consistent card shapes, typography, touch targets, and mobile spacing.
- Moved the existing five primary navigation links to a fixed bottom navigation bar at widths up to 768px. Added safe-area padding, page clearance, and active feedback. Account/cart controls remain in the compact header.
- Added language controls to the landing page and authentication pages.
- Expanded English translations across public pages, signed-in pages, empty states, errors, forms, dialogs, accessibility labels, counters, dates, and notifications.
- Fixed translations for body-level dialogs/toasts and changing attributes, without changing input values. Preserved personal names and chat content.
- Localized native confirmation dialogs. AI requests now carry the selected language through the API to the system prompt; conversation histories are separated by language.
- Added restrained navigation, card, and feedback motion; retained landing reveals and immediate route changes. Reduced-motion preferences disable decorative motion and smooth anchor scrolling.

## References

- [Android/Material navigation guidance](https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns?hl=en): compact navigation with three to five primary destinations.
- [Too Good To Go](https://www.toogoodtogo.com/en-us): food imagery, clear benefits, and a simple explanation of the reuse journey.

## Verification

- Headless Chromium: 17 routes at 1440px, 390px, and 320px in English and Indonesian. Checked runtime errors, document overflow, and mobile navigation position.
- Interactive checks: EN → ID → EN, password visibility accessibility labels, authentication error, body-level toast, populated product dialog and orders, edit-profile/store dialogs, create-store form, and AI prompt submission.
- Visually reviewed desktop/mobile landing pages and mobile forms, product details, and order cards. Checked reduced-motion rendering.
- `npm --prefix frontend run test:i18n`: catalog, dynamic counters/dates, preserved content, and whitespace normalization.
- AI service contract checked with a mocked Groq client for English, Indonesian, and English recommendations.
- `npm --prefix frontend run build` and JavaScript syntax checks.

## Boundaries

Browser API responses were local test fixtures, covering populated and empty states without modifying real accounts. Live authentication, payment, shipping, and generated AI responses require their configured services and were not exercised. Product descriptions, personal names, chat messages, and official address names remain authored content rather than automatic machine translations. No deployment was performed.
