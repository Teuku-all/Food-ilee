# Pemeriksaan UI/UX — 26 Oktober 2026

## Perubahan

- Merapikan warna permukaan, hierarki tipografi, spasi, ukuran tombol, fokus keyboard, dan shadow bertingkat untuk kartu, menu, tabel, serta popup.
- Menghapus ikon navbar aktif duplikat yang sebelumnya diposisikan terpisah dari navbar. Ikon dan label kini berada dalam satu dock mobile dengan ruang safe area.
- Membatasi tinggi menu akun, menyediakan scroll pada layar landscape, serta mendukung ArrowDown, Escape, dan perpindahan fokus.
- Memperbaiki crash profil berisi data akibat referensi variabel stok yang tidak tersedia.
- Memperbaiki listener keranjang yang terpasang berulang setelah render baris; stok habis tidak dapat dipilih untuk checkout.
- Menempatkan ringkasan checkout mobile setelah isian yang diperlukan, memperbaiki popup produk/transaksi, dan menyediakan navigasi keyboard pada tab toko.
- Memperbaiki formulir login agar isian tetap tersedia saat request gagal, aksesibilitas password, serta layout formulir toko, AI, dan percakapan.
- Membatasi CSS tabel admin pada halaman admin, memperbesar teks dan kontrol, serta menyediakan scroll horizontal yang dapat difokuskan pada tabel/grafik mobile.
- Memisahkan CSS seluruh renderer halaman dan banner marketplace ke `frontend/styles/pages/`, memakai helper pemuatan bersama, dan menambahkan komentar pada lifecycle kontrol serta struktur tampilan.

Panduan pemeliharaan ada di [frontend-ui.md](frontend-ui.md).

## Verifikasi

- Browser Chromium lokal: 16 rute utama pada lebar 320, 390, 768, 1024, dan 1440 piksel (80 kombinasi); tidak ditemukan runtime error, overflow horizontal dokumen, atau loading yang tertinggal.
- Versi Inggris: 32 kombinasi rute/ukuran layar pada 320 dan 1440 piksel, tanpa overflow horizontal atau error JavaScript.
- Navbar pada Indonesia/Inggris, landing dan akun pemilik toko, scroll atas/tengah/bawah, serta perubahan tinggi viewport 844 → 700 → 844 piksel.
- Menu akun menggunakan keyboard dan viewport landscape.
- Interaksi keranjang: kuantitas, pilih semua, pemasangan listener, stok habis, serta tumpang tindih kolom pada enam ukuran layar.
- Popup produk, detail transaksi, profil, dan tab toko dengan keyboard; tampilan dialog pada layar sempit.
- Sepuluh keadaan gagal API dan sepuluh keadaan kosong dengan respons lokal; pemeriksaan formulir login saat request gagal.
- Pemeriksaan CSS admin setelah berpindah halaman, sehingga tabel di luar halaman admin tidak terpengaruh.
- Sepuluh pengujian frontend lulus, 56 file JavaScript lulus pemeriksaan sintaks, dan format file yang diubah lulus Prettier.
- Build produksi lulus; 16 rute hasil build dibuka tanpa error JavaScript atau respons aset 404. Gambar dan stylesheet yang memakai nama aset ber-hash berhasil dimuat.

Semua data browser berupa fixture lokal. Pengujian ini tidak melakukan login ke akun asli, pembayaran, pemesanan kurir, unggahan ke penyedia eksternal, atau deployment. Integrasi layanan asli tetap memerlukan backend dan kredensial yang sesuai.
